* Git
  #+ATTR_REVEAL: :frag (appear)
  - avoid using merge in local branches
    #+ATTR_REVEAL: :frag (appear)
    - makes history ugly and may result in duplicate commits in PR
  - run following command to use rebase on pull
    #+BEGIN_SRC shell
    git config --global pull.rebase true
    #+END_SRC
** git rebase -i
To rebase last 10 commits run
   #+BEGIN_SRC shell
git rebase -i HEAD~10
   #+END_SRC
** rebase options for commits
#+ATTR_REVEAL: :frag (appear)
- Changing order of commits is done by simply reordering lines
- =squash=: squash with previous commit
- =fixup=: like squash but discard squashed commits commit message
- =reword=: change commit message without changing commit content
- =edit=: make changes to commit (add/change files etc)
** git bisect
#+ATTR_REVEAL: :frag (appear)
- bisect is useful when you know one commit where something works
- start bisect with following command
  #+BEGIN_SRC shell
  git bisect start [good revision] [bad revision]
  #+END_SRC
- check commit history with command
  #+BEGIN_SRC shell
  git bisect visualize
  #+END_SRC
- mark current commit good or bad
  #+BEGIN_SRC shell
  git bisect [good|bad]
  #+END_SRC
- stop bisect
  #+BEGIN_SRC shell
  git bisect reset
  #+END_SRC
