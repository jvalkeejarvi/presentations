* Purpose of a unit test
:PROPERTIES:
:CUSTOM_ID: purpose
:END:
#+ATTR_REVEAL: :frag (appear)
- verify that the tested unit works as expected using it's public interface
- internals (eg. private fields/properties/methods) should never be exposed because of testing

* Public interface of a component
:PROPERTIES:
:CUSTOM_ID: public
:END:
#+ATTR_REVEAL: :frag (appear)
- markup
- parameters
- event callbacks

* What not to test
:PROPERTIES:
:CUSTOM_ID: nottotest
:END:
#+ATTR_REVEAL: :frag (appear)
- internals of the component
- injectables (services); use mocks instead
- very complex/heavy child components; use stubs instead
- 3rd party components from libraries; use stubs instead

* Locating an element by text content
:PROPERTIES:
:CUSTOM_ID: locatebytext
:END:
#+ATTR_REVEAL: :frag (appear)
#+BEGIN_SRC html
<button>Add new</button>
#+END_SRC
#+ATTR_REVEAL: :frag (appear) :code_attribs data-line-numbers='1|2|'
#+BEGIN_SRC csharp
var addButton = cut.Find("button:contains('Add new')");
addButton.Click();
#+END_SRC

#+ATTR_REVEAL: :frag (appear)
=:contains= CSS selector can be used to find an element by text content

* Locating an input by label
:PROPERTIES:
:CUSTOM_ID: locatebylabeltext
:END:
#+ATTR_REVEAL: :frag (appear)

* Verifying markup
:PROPERTIES:
:CUSTOM_ID: verify
:END:
#+ATTR_REVEAL: :frag (appear)
#+BEGIN_SRC html
<ul>
    <li>Item1</li>
    <li>Item2</li>
</ul>
#+END_SRC

#+ATTR_REVEAL: :frag (appear) :code_attribs data-line-numbers='1|2|'
#+BEGIN_SRC csharp
var rows = cut.FindAll("li").Select(x => x.TextContent);
rows.Should().BeEquivalentTo(["Item1", "Item2"]);
#+END_SRC
